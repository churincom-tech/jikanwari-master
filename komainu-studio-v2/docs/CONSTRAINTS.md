# 制約契約 v1

H-001 教員の同時担当禁止。H-002 同一種別の教室数を超えない（普通教室も登録容量を使う）。H-003 各授業IDの必要時数と配置時数が厳密一致、配置属性は授業正本と一致。H-004 勤務不可・非常勤勤務日を厳守。H-005 固定枠のID/授業/クラス/位置を全件保持。H-006 クラス同時重複禁止。H-007 requiredは同日隣接2コマの組。H-008 空きは日末に寄せる。H-009 固定数は週時数以下。H-010 既存の自動日課目標に一致。H-011 同一授業の隣接は給食境界をまたがない。H-012 noneは同一授業の隣接不可。H-013 設定曜日・使用限数の範囲内。追加の整合検査: 同一クラス同一教科の1日上限（対象行の最小上限）、未知ID/授業属性の改ざん禁止。

## H-010の正確な意味

各クラスの全必要時数に対し曜日上限から中央曜日優先で1枠ずつ減らす。固定時限まで各日を延ばし、その分を固定時限より後ろの他日から減らす。目標時数合計が必要時数と一致しない場合は矛盾。この規則は従来互換であり、自由な日課探索ではない。UIで日別目標を見せ、利用者は曜日上限/固定枠で調整する。隠れた規則緩和はしない。

## ソフト条件

既存S-001–007（主要教科偏り、同日重複、教員の空き/連続、特別教室集中、非常勤出勤日、日々の負荷、連続希望）を維持。ハードと異なり満足を保証しない。内訳と改善候補を表示する。

## 検証マトリクス

独立oracleは本番validator/solverを呼ばず、入力と配置だけから各不変条件を計算。全ハード条件・ID一致・1日上限に違反する変異を作り検出する。小問題は独立列挙器で全配置を数えて0/1/複数を比較。60学校は先に作った配置をwitnessにし、その配置から互換する時数・勤務不可・固定・室数を導く（探索器の出力を正解に使わない）。各3/6/9/12/18クラス12seed、必要連続/連続希望/短縮日/非常勤/共有資源を混ぜる。200性質ケースは改名・順列・JSON往復・時数増減を再現seed付きで記録。過密や勤務不可など24異常ケースを別集計する。
