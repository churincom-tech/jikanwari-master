# V2 変更・互換性

## UI・教育課程の簡単変更（2026-09-26追補）

- 進捗欄の低コントラストと内円の重なりを修正。SVGリングが実際の割合に追従し、100%は一周表示。
- 工程遷移・候補・ボタンに短い動きを追加。動きを減らす設定では停止。
- 授業情報に「新教科を追加」「週時数を変更」「教科を廃止」の3ボタンを追加。変更前後・担当・削除件数を確認して基準と授業情報へ反映。
- 週0時間の学年だけの除外、固定枠の明示削除確認、反映後Undo、別の課程版・他週・既存年間目標の保護。
- 生成アルゴリズム・保存キー・JSON version5は変更なし。旧V2 ZIPを残し、更新版は別名で配布。

|項目|V2|互換性|
|---|---|---|
|学校/教員/教室/授業/固定枠|維持、給食境界と目標日課を可視化|旧JSONを明示読込|
|課程マスタ・版・年間目標・A/B|維持、変更時の参照切れを修正|新教科は担当確認が必要|
|候補生成|MRV空き枠探索、前方検査、バックトラック、探索順序の再試行|固定/時数等の必須条件は緩和しない|
|候補数|異なる配置を最大3案|1案しかないときの重複候補を廃止|
|探索状態|中止/時間切れ/矛盾/部分案/完了を分離|同期600試行から変更|
|候補最終検査|勤務日、属性一致、固定欠落、日上限、普通教室容量を追加|違反する旧候補は読込時破棄|
|保存|V2専用キー、保存失敗通知、破損データの非上書き・救出|旧領域不変、version5|
|Undo|入替・読込・課程変更に加え白紙開始の復帰|次の入力変更まで|
|画面|コンパクトな進捗、結果主役、狭幅工程2行、JSON保存常時到達|既存操作は保持|
|検証|独立oracle、変異、小全探索、60学校、性質検査、実ブラウザ|旧版テストは期待の違いを明示|

ロールバック: V2を閉じて旧版を開くだけです。旧版のコード・保存データは書き換えていません。
