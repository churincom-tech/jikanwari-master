## 修正した主な問題

- 同じ配置を別候補として重ねる問題。異なる配置だけを最大3案にしました。
- 勤務日、普通教室数、授業属性、固定枠欠落などの最終検査漏れを補いました。
- 難しい配置で探索が停滞する問題。枠の選び方と制約検査、時間内の探索順再試行を改善しました。必須条件は緩和しません。
- 探索中の入力変更・中止による古い結果の混入を防ぎました。
- 教育課程の連続入力で内部参照が切れ、入力が欠ける問題を修正しました。
- 自動保存の失敗や破損を通知し、元データを保存できるようにしました。
- 結果画面の説明領域を縮め、時間割と候補比較を優先しました。

実校の年間運用、個別学校の全条件、iOS/Safari、実タブレット、Chromebook、他PC、物理プリンタ、独立した教務担当者による使い勝手評価はNOT_RUNです。UIの視覚レビューは実装者による自己レビューで、第三者認証ではありません。アクセシビリティの包括認証でもありません。

必須条件が矛盾する場合や時間内に見つからない場合があります。全希望の同時達成・最適解・あらゆる組合せでの無欠陥は保証しません。部分結果は「有効な案が要求数より少ない」意味であり、不完全な時間割を完成扱いしません。合同授業・同時開講・TTなど、1授業1クラス1担当で表せない条件は対象外です。

検査コードと機械可読の実行結果は開発用フォルダに保持し、配布ZIPからは除外しています。通常利用に開発用Node/Pythonやネットワークは不要です。
