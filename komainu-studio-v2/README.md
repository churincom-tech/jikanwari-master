# コマいぬ Studio V2

中学校の時間割案を、学校・教員・教室・授業・固定枠の条件から作るローカルWebアプリです。

## 開き方

フォルダ全体を展開して **index.html** をChromeまたはEdgeで開いてください。インストール、Node、Python、インターネット接続は利用時には不要です。HTMLだけを別の場所へ移さず、scripts / assets / CSSも一緒に置いてください。

## 最初の操作

1. 学校情報で曜日・時限・給食の境目・学年・クラス数を設定します。
2. 授業情報で教員、勤務日・勤務不可、教室数、各クラスの授業と週時数を入力します。
3. 条件設定で固定枠と「作成に使う日課」を確認し、「この条件で時間割を作る」を押します。
4. 異なる候補を最大3案表示します。クラス・全クラス・教員・教室で切り替え、比較・安全な入れ替え・印刷ができます。

初期状態は白紙0%。画面移動だけでは進捗は増えません。操作を試すときは学校情報の「使い方・サンプル」から架空データを読み込めます。

## 保存・旧版からの移行

入力は**このブラウザ・この起動場所**のV2領域に自動保存されます。定期的に「JSON保存」でファイルへ退避してください。ブラウザのデータ削除、別ブラウザ、フォルダ移動、file起動とHTTP起動の切替では保存領域が変わることがあります。

旧版StudioのJSONは「JSON読込」から確認後に取り込めます。旧版アプリ・旧版の自動保存は変更しません。読込・白紙開始の直後は「元に戻す」が使えます。別の入力変更を行うと直前Undoは終了します。V2 JSONのappは `komainu-studio-v2`、versionは5です。

自動保存に失敗した場合は画面下に通知します。「JSON保存」で退避してください。壊れた自動保存を検出した場合は元データを上書きせず、「復旧用JSONを保存」が表示されます。

## 時数・課程の変更

授業情報の上部にある **「教育課程の変更」** から設定できます。

- **新教科を追加**：名前・学年別週時数・教室・配置ルールを入力し、「変更内容を確認」。担当教員をクラス別、または一括で明示して反映します。
- **週時数を変更**：教科を選んで学年別の時数を変更。クラスごとの「変更前 → 変更後」を確認して、一度で基準と授業情報へ反映します。
- **教科を廃止**：教科を選ぶと、取り除く授業と固定枠の件数を表示します。確認チェックと最終確認の後に反映します。基準の記録・教員・教室・別の課程版は残します。

ある学年だけ実施しない場合は週時数を0にします。該当学年の授業・固定枠を取り除く前に確認できます。反映直後は「元に戻す」が使えます。事前にJSON保存しておくと、後日も元の設定へ戻せます。

時数変更は現在選択している週パターンへ適用されます。他の週の既存時数と既存の年間目標は変えません。廃止は現在の課程版全体で教科を対象外にします。年間目標、A/B週、改定案の複製は下の「詳細設定」から管理できます。

詳細設定の教科マスタだけを直接編集した場合は、従来どおり「既存へ反映」または「全クラスへ一括展開」が必要です。簡単変更の3ボタンでは基準と授業情報へまとめて反映します。

課程の版・年度、年間目標、A週/B週を管理できます。年間目標は週時数へ自動変換しません。週0.5コマを直接配置せず、A/B週などで整数時数に分けて設定します。技術・家庭など合算管理する教科は配分を確認してください。課程・入力条件が変わると古い候補は無効になります。

## 必須条件と希望条件

- 必須: 必要時数、教員重複・勤務、教室数、固定枠、クラス重複、連続必須、給食境界、1日上限、日課・使用枠など。
- 希望: 教員の空き時間、主要教科の偏り、非常勤の出勤日、連続優先など。得点と警告に反映しますが、全希望の同時達成や最適性は保証しません。
- 空きコマは各日の末尾にまとめます。日別目標は曜日上限・週時数・固定枠から計算します。条件設定の「作成に使う日課」で確認できます。

## 案が出ないとき

「入力の修正が必要」「設定内の探索を完了したが配置不可」「時間切れ」を分けて表示します。時間切れは不可能の証明ではありません。固定時限、勤務日、必要時数、教室数、日課を確認してください。探索設定の番号を変えて再試行もできます。探索は15〜60秒で区切り、中止ボタンは入力を消しません。解が1つしかない条件で同じ案を3つ表示しません。

## 検証範囲と限界

検証結果は docs/VALIDATION.md を参照してください。対象はWindowsのChrome/Edge、合成学校3〜18クラスと小問題・異常系です。実校の最終運用判断、全ての理論上の組合せ、iOS/Safari、Chromebook、物理印刷を保証するものではありません。合同授業・同時開講・TTなど、現在の1授業1クラス1担当モデルで表せない条件を別々の授業へ無理に変換しないでください。

## 開発用検査

tests は開発者向けで、通常利用には不要です。検査はNodeとPlaywrightを使います。配布ZIPには開発用依存やテスト用ブラウザプロファイルを含めません。
