# Scoring And H-010 Revision Check

## 実施日
2026-07-17

## 対象と証拠境界
承認済みのS-001主要教科偏り、S-005非常勤出勤日集約、H-010日別目標の責務整合、関連表示と回帰試験だけを対象とした。検証データはプロジェクト前提から作った代表シナリオであり、実学校データによる適合証拠ではない。

## 実装結果

| 項目 | 実装 |
| --- | --- |
| S-001 | クラス別に国語・社会・数学・理科・英語を集計し、曜日集中と給食後の配置比率が許容範囲を超えた分を1コマ2点で減点。候補へ警告と改善案を追加 |
| S-005 | 非常勤教員別に、総授業数、1日の時限数、各授業の同日上限から理論上の最少出勤日を求め、実出勤日の超過を1日2点で減点。候補へ出勤日数と集約案を表示 |
| ソフト設定 | S-001〜S-007の全チェックを採点処理へ接続。無効時は対応内訳、警告、改善案を生成しない |
| H-010 | クラス週時数、曜日別上限、固定授業を使う日別目標計算を共通化し、生成器と候補検証が同じ目標を使用 |
| H-013 | 学校情報にない曜日、1未満・非整数・曜日別上限超過の時限を独立したハード制約として検出 |
| 表示 | 先頭8件の候補警告に非常勤の運用改善が現れるよう、S-001・S-005を優先評価 |
