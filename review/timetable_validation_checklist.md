# Timetable Validation Checklist

## ハード制約
- [ ] H-001: 教員の同時刻重複がない
- [ ] H-002: 特別教室の同時刻利用数が教室数を超えない
- [ ] H-003: 教科ごとの必要時数を満たす
- [ ] H-004: 勤務不可時間に授業がない
- [ ] H-005: 固定枠が変更・欠落していない
- [ ] H-006: クラスの同時刻重複がない
- [ ] H-007: 2時間連続必須の授業が隣接2時限で配置され、片側だけ固定されていない
- [ ] H-008: 各クラスの途中時限に空きがなく、空きは日の末尾に寄っている
- [ ] H-009: 固定授業が授業情報の週時数を超えていない
- [ ] H-010: 各クラスの日別授業数が目標日課内に収まり、極端な日別差がない
- [ ] H-011: 2時間連続授業が給食をまたがない
- [ ] H-012: 2時間続き設定のない授業が同日に隣接していない
- [ ] H-013: 学校情報で使わない曜日や時限に授業がない

## ソフト制約
- [ ] S-001: 主要教科の曜日・午前午後の偏りが数値または説明で確認できる
- [ ] S-002: 同一教科の同日集中が過度でない
- [ ] S-003: 教員の空き時間や連続授業が極端でない
- [ ] S-004: 特別教室利用が極端に集中していない
- [ ] S-005: 非常勤教員の出勤日が不必要に増えていない
- [ ] S-006: クラスごとの日々の負荷が極端に偏っていない
- [ ] S-007: 2時間連続が望ましい授業の未連続理由が説明できる

## 入力診断
- [ ] 教員・教室・クラスの固定授業競合を生成前に検出できる
- [ ] 非常勤の勤務日不足と勤務不可による容量不足を説明できる
- [ ] 実現不能条件を正常候補なしとして明示できる

## 記録
- 検証結果は `artifacts/verification/` に残す
- 代表シナリオと実学校データの証拠境界を明記する
- 使用したテスト、候補数、コマ数、スコア、実行時間、未評価項目を記録する
